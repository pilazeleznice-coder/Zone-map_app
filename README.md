# Zone-map_app

Mapa rozvozu Pila Železnice s leteckým podkladem Mapy.com, našeptávačem adres, plánováním zastávek a ceníkem dopravních zón.

Aplikace je v souboru `index.html` a nevyžaduje sestavení. Pro mapy, adresy a trasování je potřeba internet.

## Publikování

GitHub Pages: větev `main`, složka `/ (root)`.

Ceny zastávek se určují samostatně od pily. Navigace a čas jsou orientační pro automobil.
